# YouTube RAG Chatbot

A Retrieval-Augmented Generation (RAG) system for querying YouTube video transcripts using LLMs.

## Features
- YouTube transcript ingestion
- Transcript chunking
- FAISS vector search
- Semantic retrieval
- Gemini-powered responses
- LangChain pipeline

## Tech Stack
- Python
- LangChain
- FAISS
- HuggingFace Embeddings
- Gemini API
